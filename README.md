# Peg Drop (onyx-fun-plinko)

Casual original Avatar-Plinko-style demo for Harry / WG-Mojo.
Inspired loosely by research on gift-driven Plinko — **not** a clone of any competitor.

## Pages

| Page | Use |
|------|-----|
| `browser-source.html` | OBS / LIVE Studio Browser Source (clean, transparent-friendly) |
| `hosted.html` | Normal browser / window capture with demo gift buttons |
| `index.html` | Landing links |

Both game pages include `noindex, nofollow`.

## GitHub Pages URLs (once enabled)

- Hosted: https://wg-mojo.github.io/onyx-fun-plinko/hosted.html
- Browser source: https://wg-mojo.github.io/onyx-fun-plinko/browser-source.html
- Index: https://wg-mojo.github.io/onyx-fun-plinko/

## Demo controls

- Hosted page: gift buttons
- Browser source query: `?gift=rose|mid|galaxy|lion|likes` or `?auto=1`
- Optional: TikFinity Desktop WebSocket `ws://localhost:21213/` when available

## Gift bindings (loose)

- Rose → a few balls
- Perfume (mid) → more balls
- Galaxy → ball rain
- Lion → one giant heavy ball
- Likes → small balls
